# 代表性示例

以下示例来自固定测试集的已完成评测，展示模型行为差异；它们不构成整体质量胜率。

## 西班牙语问候

**问题**：`“早上好”在西班牙语中怎么说？`

**Spark-X2.5-4B**：给出 `Buenos días`，并继续扩展说明；扩展中把 `Buenas tardes` 与女性早间问候混用。

**LoRA v1**：`“早上好”在西班牙语中可以说 “Buenos días”。`

微调后保留核心答案，避免了这次错误扩展。

## 商品抽取

**问题**：从钢琴选购说明中识别产品词，以 JSON 列表返回。

**参考集合**：钢琴、弦线、琴锤、立式钢琴、三角钢琴、二手钢琴、新琴。

**Spark-X2.5-4B**：把品牌、质量、音色、价格等属性或选购维度误当作商品。

**LoRA v1**：返回钢琴、立式钢琴、三角钢琴；误抽减少，但仍漏掉弦线、琴锤、二手钢琴、新琴。

## 场景应答

**问题**：打网球需要的防晒用品有哪些？

**Spark-X2.5-4B**：回答较长，覆盖防晒霜、遮阳帽、太阳镜和防晒衣等用品。

**LoRA v1**：回答更短，但“防晒霜喷雾：方便携带，随时补涂”在第 5、7 项重复出现。

## 流量概念解释

**问题**：请解释“波澜不惊的流量曲线”指什么。

**Spark-X2.5-4B**：从网站、内容平台和业务系统等场景展开解释，共约 808 token。

**LoRA v1**：用约 45 token 说明流量平稳、没有明显波动，表达更直接，但省略了部分应用背景。
